A program that draws one image summing up the world's news of Thursday 26 November 2026: a "THE WORLD IN ONE DAY" newspaper with 43 dated stories across 10 regions, three hero stories, a black stats bar, a UTC timeline, a world map and a date check.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
